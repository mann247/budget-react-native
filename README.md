# Budget Tracker (React Native)
A mobile budget tracking application built with React Native. This app allows users to track income and expenses, helping them better understand spending habits and manage finances on the go.

This project focuses on mobile UI development, state management, and building interactive components in a React Native environment.

# 🚀 Features

1. Add income and expense entries

2. Display a list of transactions

3. Calculate and display current balance

4. Mobile-friendly UI built for iOS and Android

5. Real-time updates using component state

# 🛠️ Technologies Used

1. React Native
2. JavaScript (ES6+)
3. Expo
